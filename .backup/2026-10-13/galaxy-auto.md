## TL;DR (For humans)
**What you'll get:** Cửa hàng phần mềm GALAXY AUTO tiếng Việt: năm sản phẩm riêng, bảng giá theo từng game, mua bằng chuyển khoản, khu vực khách hàng/quản trị và bản quyền nhiều thiết bị. Nhận diện Golden Immortal Galaxy từ prompt gốc: thiên hà xanh đen, cung điện/núi tiên và ánh vàng; chất kim loại fantasy/MU dùng tiết chế, đúng artwork từng game. Ưu tiên chọn đúng gói, hiểu trạng thái thanh toán, tải và quản lý phần mềm; không biến quy trình mua thành giao diện game.

**Why this approach:** Một ứng dụng chia module rõ ràng giúp dễ bảo trì mà không dựng hạ tầng phức tạp quá sớm. Giá, giao dịch và quyền sử dụng được kiểm tra phía máy chủ. Giao diện dùng chung cấu trúc so sánh gói và thao tác, khác biệt từng game bằng artwork/nội dung; mỹ thuật không che khuất thông tin nghiệp vụ.

**What it will NOT do:** Không bịa tính năng, tương thích, giá hoặc đánh giá. Không tự động chuyển tiền, sửa phần mềm game, vượt bảo vệ game hoặc hứa kiểm soát được client chưa tích hợp. Không tự triển khai lên môi trường thật.

**Effort:** XL
**Risk:** High — tiền và bản quyền cần xử lý đồng thời chính xác; dữ liệu thương mại, tài sản hợp pháp và tích hợp client thật là điều kiện mở bán riêng.

**R7 — License lifecycle.** New purchases create separate licenses; explicit renewal targets same customer's/product's license. State `unactivated|active|suspended|revoked`; expired is derived from `expires_at <= now`, not a delayed cron. A suspended license remembers prior state; restore does not reset time or clear expiry. Revocation terminal; replacement is a separately audited admin grant. Admin manual grants require explicit product/duration/cap/recipient/reason, not undocumented infinite licenses. Random 256-bit license keys, hash/HMAC lookup, encrypted recoverable value (AES-GCM, dedicated server key/version) for authenticated owner reveal/download; never plaintext DB/logs/URLs. Reveal is step-up authenticated and audited. First successful activation under row lock starts `activated_at` once and `expires_at=activated_at+duration_days*86400` UTC. All devices share expiry. Concurrent device registration locks license and enforces snapshot cap. Device ID is random installation UUID + secret credential, not hidden hardware fingerprint, not claimed tamper-proof. Idempotent repeat activation for an existing device requires its credential; leaked license key alone cannot evict existing devices. Owner/admin may deactivate a registered device with recent authentication, audit and reason; expiry never resets. Registered-device count is NOT concurrent-game-session control. Renewal allowed only for an already-activated non-suspended/non-revoked license, same product and same device cap; active extends from max(now, expires_at), expired from now; duplicate settlement cannot extend twice. Different cap purchase creates a separate license, clearly labelled. Renewal confirmation identifies the target with a non-secret reference and distinguishes first activation from renewal settlement; R15 specifies estimated versus actual expiry messaging.

**R8 — External licensing API and downloads.** Versioned `/api/v1/licenses/activate`, `/refresh`, `/deactivate`; JSON request schemas and stable machine error codes with Vietnamese message in `docs/api/license.openapi.yaml`. Activate accepts key/product/install UUID; new device secret returned once; idempotency retry encrypted response retained 10min then requires recovery/deactivation, not fresh admission. Refresh requires device secret, rechecks account/license/device/product. Return signed Ed25519 JWT with `iss,aud,license_id,product_id,device_id,jti,iat,exp,kid`; `exp <= min(now+300s,license_expiry)` and reject at equality; public JWKS with overlap rotation. No offline grace; no refresh after revoke/suspend, prior lease valid only to expiry. Client must validate signature, audience, expiry and stop safely when unable to refresh. Rate limiting persisted server-side by endpoint/IP and key/device hash (no raw secrets): activation 10/min/IP and 5/min/key, refresh 60/min/device and 120/min/IP, 429+Retry-After; trusted proxy IP parsing documented, malformed/unknown keys count too. No claim of real binary enforcement until each client integrates and is tested. Contract simulator demonstrates protocol, not game automation. Private software bucket; verify owner entitlement before 60s signed link, unactivated valid license may download without activation, expired/suspended/revoked denied; anonymous access only if admin explicitly marks release public. Customer-owned signed links may remain usable for their remaining TTL, do not claim instantaneous revocation. Admin external download URLs allowed HTTPS on configured trusted origins only; public external links explicitly public; protected release must use managed private storage or a verified signed-link adapter, never a permanent public URL disguised as private.
